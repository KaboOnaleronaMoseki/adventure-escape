# Adventure Escape

A simple single-page HTML site for Kabohamo Automotive providing workshop services, vehicle administration, and booking information.

This repository currently contains:
- kabohamo_automotive_naked.html — the site's HTML page
- commit-1.txt — placeholder file created during repository updates

How to use
